# 🚀 Installation

## Method 1 (Recommended)

### Step 1

Visit the official download page.

Download the latest version of **SkyCast**.

### Step 2

Download

```
SkyCast_Setup.zip
```

### Step 3

Extract the ZIP file.

### Step 4

Run

```
SkyCast_Setup.exe
```

### Step 5

Click

```
Next
```

### Step 6

Choose the installation folder.

(Default)

```
C:\Program Files\SkyCast
```

### Step 7

Click

```
Install
```

### Step 8

Wait for installation to complete.

### Step 9

Click

```
Finish
```

### Step 10

Launch SkyCast from

- Desktop Shortcut

OR

- Start Menu

# 💻 Run from Source Code

Clone the repository

```bash
git clone https://github.com/devtejss/Sky-Cast.git
```

Open the project

```bash
cd Sky-Cast/app
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create

```
config.py
```

Paste

```python
API_KEY = "YOUR_OPENWEATHER_API_KEY"
```

Run the application

```bash
python main.py
```

# 🔑 OpenWeatherMap API

SkyCast uses the OpenWeatherMap API.

Create a free account and generate an API key.

Website:

https://openweathermap.org/api

---

# 📦 Build Executable

Install PyInstaller

```bash
pip install pyinstaller
```

Generate executable

```bash
pyinstaller --onefile --windowed --icon=assets/logo.ico --name SkyCast main.py
```

The executable will be generated inside

```
dist/
```
